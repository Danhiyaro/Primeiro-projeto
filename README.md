# 🌐 Primeiro Projeto — Desenvolvimento Front-end

Meu primeiro projeto de desenvolvimento front-end desenvolvido durante a graduação em Ciência da Computação.

O projeto foi criado para praticar os fundamentos de desenvolvimento de páginas web, estruturação de conteúdo, navegação entre páginas e organização de arquivos HTML e CSS.

## 🎯 Objetivo

O objetivo principal deste projeto foi colocar em prática os primeiros conceitos de desenvolvimento web aprendidos em aula, especialmente a criação e organização de páginas HTML e a aplicação de estilos utilizando CSS.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3

## 📚 Conceitos praticados

* Estrutura básica de documentos HTML
* Criação de múltiplas páginas
* Links e navegação entre páginas
* Organização de conteúdo
* Inserção de imagens, áudio e vídeo
* Estruturação de páginas
* Estilização utilizando CSS
* Organização de arquivos e pastas

## 📁 Estrutura do projeto

O projeto possui diferentes páginas e recursos utilizados durante o desenvolvimento:

* `index.html`
* `blog.html`
* `contato.html`
* `pag1.html`
* `pag2.html`
* `style.css`
* `img/`
* `audio/`
* `video/`

## 🚀 Como executar

1. Clone este repositório:

```bash
git clone https://github.com/Danhiyaro/Primeiro-projeto.git
```

2. Abra a pasta do projeto.

3. Execute o arquivo `index.html` em um navegador.

## 🧠 O que aprendi

Este projeto representa meu primeiro contato prático com desenvolvimento web e foi importante para entender como páginas HTML são estruturadas, como diferentes arquivos podem se relacionar e como o CSS pode ser utilizado para melhorar a apresentação do conteúdo.
